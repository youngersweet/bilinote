# 产品检查与本次改进

## 已修正

| 问题 | 改进 |
| --- | --- |
| 深色图标导航缺少文字，新用户需猜入口 | 浅色侧栏、图标加文字、明确的添加主按钮 |
| 提取和总结目标藏在高级设置 | 添加窗口直接选择生成知识笔记或仅提取正文 |
| 首页模型设置实际进入常规页 | 直接进入模型页 |
| 改模型后点完成可能丢失设置 | 完成时保存待提交模型，失败留在模型页 |
| 正文已取得后下一步藏在更多菜单 | 阅读区直接显示生成笔记按钮 |
| 空笔记也能复制，得到空字符串 | 按当前标签与实际内容启用复制 |
| 日常修改目录仅检查非空 | 新建任务与设置保存前实际验证可写 |
| 字体回退导致中文不一致和阅读位置偏移 | 使用 Windows 中文系统字体并回归字号变化 |

## 仍有的产品边界

- 仍是 Windows 源码体验版，安装需要 Python，AI 总结需要外部 Codex 配置；尚不是开箱即用的独立安装包。
- 不包含完整 macOS 支持；视觉与交互参考 Apple，窗口和快捷键遵循 Windows。
- 正在运行的处理暂不提供安全中断，只能取消等待项；托盘退出会等待运行任务结束。
- 批量删除仍为确认后永久删除，尚无应用内回收站；本次未改变用户已有删除语义。
- 平台登录与接口可用性、模型额度等需真实联网验收，界面测试不能证明所有视频都可处理。
