# 发布到 GitHub

本地目录已按独立仓库准备。先在 GitHub 创建自己的空仓库（可先设为 Private），然后在项目目录执行：

```powershell
git init -b main
git add .
git diff --cached --stat
git commit -m "Initial Bili Note desktop release"
git remote add origin https://github.com/YOUR_NAME/bilinote.git
git push -u origin main
```

将 YOUR_NAME 替换成实际账号。上传前核对暂存文件，不加入登录、Cookie、API key、个人笔记或模型。仓库名称可能与其他 BiliNote 项目相似，请用自己的项目说明和来源声明。

推送后查看 Actions 的 Windows checks；通过后下载 BiliNote-windows-source artifact，或本地运行 `python scripts/package.py`。创建 GitHub Release（例如 v0.1.0），上传其中的源码 ZIP，并明确写明 Windows / Python 3.13 / Codex 要求。这不是独立 EXE 安装包。

当前自动化只测试离线逻辑；B站登录、实际视频提取、所选账号的模型权限和联网转写应在发布前用测试账号验收。不要把离线测试通过描述成所有视频均可用。
