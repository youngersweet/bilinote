# Bili Note 内容笔记规则

## 获取：够用即停

- 对每个分集按“可下载字幕 → 已授权浏览器的字幕正文 → 完整音轨本地转写”顺序回退。
- 字幕正文可用时直接整理，不再执行后续浏览器读取、音频下载、ASR或抽帧；不要把所有获取方式一并运行。
- 字幕获取不到时才使用下一条路线。接口错误、权限问题、空字幕列表和字幕质量不可用分别记录，不能伪装为成功。
- 用户明确选择音频转写时，使用本机faster-whisper small模型，处理所选分集的完整音轨；验证音轨时长和尾部可解码，保留原始转写。
- 只有本地转写需要校正或用户主动选择补充画面时，才提取联系图并按需看单帧。抽帧完成不等于已核对画面，只有视觉模型实际处理成功后才能标记完成。
- 无论使用哪条路线，标题、简介、评论和平台AI小结都不能代替视频正文。

## 整理：核心内容充分、表达紧凑

目标是让读者仅看文档，也能掌握视频的核心知识、主要观点、关键推理与结论，并理解必要的案例、数字和适用条件。保留支撑理解的论证与限定，篇幅由本次内容决定；不继承“已经转写音轨、核对课件”的来源声明，实际证据取决于本次B站材料。

### 正文形式

- 标题用视频标题或忠实的精简标题。正文按内容转折分段，以“编号＋概括本段意思的小标题＋实际时间范围”组织，例如格式 `## 1. 本段的具体观点（MM:SS—MM:SS）`。小标题应表达内容，避免仅写“核心观点”“案例分享”等空标签。
- 每个内容段用连贯自然段讲清核心观点及其依据，保留理解结论所需的问题、推理、案例和条件。它们是写作检查点，不是每段必须套用的小栏目；没有讲到的不能补造。
- 大致顺着原视频推进，允许合并重复和局部按主题重组。不同时间的内容合并时保留各自定位，不拼出作者没有表达的先后或因果关系。
- 正文小节跟随知识和论证变化，不按固定分钟数切节，不要求每句话都带时间戳，也不固定章节数。信息密集段可以细分；长时间重复可合并，但不能省掉其中新增的论据或条件。
- 清理口头填充词、寒暄、重复复述；保留影响意思的反问、转折、强调、自我修正、保留意见及估算。不能把“可能”“个人经验”改写成普遍事实，不能替作者把未完成的推理补完。
- 必要案例保留足以说明判断的设定、关键过程、条件或数字及作者解释，不能只列案例名。同类例子合并，额外例子只有带来新条件或新论据时才保留。技术内容保留必要架构、参数、步骤、限制和失败条件；不按常识自行补齐画面里的代码或操作。
- 详略由信息量决定，核心定义、关键论证、必要案例、数字及边界要留下，表达保持紧凑；无须逐句复刻或收录所有例子，不用固定压缩率或凑字数。不要把长视频强压成几条空提纲，也不要为了篇幅添加视频未讲的背景知识。
- 默认直接进入内容，不额外套知识地图、概念卡、自测题、个人价值分析或行动清单。作者原本提出的练习和行动建议属于视频内容，应保留；助手额外建议仅在用户要求时提供，并与作者原意分开。

### 时间与B站来源

- 时间依据字幕JSON/SRT或音轨转写的原始时间，显示到秒即可，超过一小时用 `HH:MM:SS`。同一小节跨不连续内容时标多个范围，不能把中间无关内容假装成同一连续论证；不能按字数、段号或估计语速捏造时间。
- 多P必须标明P号及该集自己的时间，例如 `P2 03:10—05:42`；时间不累计成整套课程的统一时间轴。只取得所选分集就只总结所选内容。
- 如果正文没有可信的时间数据，明确说明“本材料无可靠时间轴”，继续按内容分段；不能为了形式齐全虚构时间。材料首尾有静音或字幕间隙时，不强行把每节时间填满到全片时长，也不自动断定缺失。
- 优先完整读取已取得的B站字幕。标识 `ai-zh` 等平台AI字幕来源，不能当成人工校验稿；有字幕不代表已下载或听过完整音轨，更不代表全程看过画面。
- 作者观点、自述经历、假设情景、效率或收益估算保留其归属，不转写为已独立验证的事实。对疑似字幕错词，只有上下文或已核对画面足以支持时才校正；影响结论的歧义标注待核实。
- 有已完成的视觉核对记录时，结合记录校正术语、数字和流程；看不清或音画冲突时保留不确定性。不能从“抽帧成功”推断“已核对画面”。
- 结尾用统一、简短的来源说明记录链接、所选分集、正文来源、模型核对方式及实际缺口，分别说明平台字幕、完整音轨机器转写、联系图观察和抽样单帧核对；只做了哪项就写哪项。模型核对不等于人工校验或无遗漏保证。影响具体结论的歧义在原处注明，其余覆盖局限不在每节重复；必要的关键局限可在开头用一两句提示，不堆处理日志。

### 长内容分段整理与核对

- 短视频轻量整理一次，不默认逐段核对。长视频按字幕量与时长划分材料段，所有原始字幕行都要进入某个主材料段，并保持P号与时间定位，不能只抽开头或代表片段。
- 每段可附少量同P相邻字幕作为衔接上下文；上下文不重复写入正文，不跨P拼接。正文时间取自主材料的原始字幕，开头或结尾截断的论证标明承接或未完，不自行补全。
- 每段先整理核心观点、关键论据、必要案例、数字和条件，再独立对照该段原始字幕核对补漏、删冗余及纠正原意；不能只拿上一轮整理稿再检查。分段结构化响应须明确完成且内容可用。
- 将核对后的段落按原顺序直接组装为正文，保留原定位；不再调用模型对全文合并重写，避免二次压缩丢失信息。跨段衔接与重复在分段整理和核对时结合相邻上下文处理。
- 已核对分段按材料、写作规则及模型配置缓存；重试仅复用匹配的缓存。任一分段未完成或检查失败时，不覆盖已有笔记。
- 来源如实说明已取得的字幕或转写经分段整理及模型逐段核对；不宣称最终阶段重新读取了全部原始字幕，不把模型核对写成人工复核或全程视觉审查。

### 写后检查

对照原始材料检查开头、中间、结尾的核心内容是否都有交代；时间与P号能否回查；必要案例是否讲清作用；“可能、估计、在某条件下”有无丢失；同类例子或免责声明是否重复；有无冒认音轨或画面覆盖。缺失时补原文依据，冗余时合并删减，不用外部知识填空。
